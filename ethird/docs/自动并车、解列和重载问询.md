# 自动并车、解列和重载问询

## 一、工程概述

本工程面向船舶电站自动化系统，以两台同步发电机组、船用框架式空气断路器、汇流排、自动化电站控制器（ShipAutoControl）及重载询问控制面板（侧推器）等设备构成一套完整的船舶电站仿真教学环境。学员可通过**自动演示、单步演示、演练、评估**四种教学模式，掌握船舶电站自动并车、自动解列、故障自动换机/切换以及大功率负载重载问询的工作原理与典型操作流程。

工程核心特点：

- **自动化电站**不直接驱动发电机与主开关，而是通过通信命令控制各发电机组遥控面板，由面板经既有电气机制驱动机组，贴近实船控制架构。
- 自动控制模块具备**失电自动起动、自动并车、自动解列、自动调频**四大功能。
- 内置 6 种典型故障场景，支持Ⅰ级降级故障（不停机）与Ⅱ级严重故障（跳闸失电）的自动处置演示。
- 侧推器重载问询面板演示"询问 → 等待 → 并车 → 允许 → 起动"的大功率负载安全接入流程。

## 二、系统组成

| 设备 | 作用 |
|------|------|
| 1#/2# 同步发电机组 | 主电源，额定 80kW / 400V / 50Hz |
| 主开关 QF1、QF2 | 船用框架式空气断路器，实现并网与解列 |
| 汇流排 | 各机组的公共母线，向负载供电 |

| 重载询问面板（侧推器） | 大功率负载起动前的询问交互界面 |
| 失压脱扣电源 | 主开关失压脱扣控制电源 |

## 三、核心教学技能点

### 1. 失电自动起动
自动化电站处于**自动模式**时，一旦检测到母线失电，按备用顺序（1-2-3 或 2-1-3）自动起动第一台备用机组，待建压储能完毕后自动合闸向母线供电。

### 2. 自动并车
单机在网运行、负载超过并车阈值（单机额定功率的 50%）时，电站自动起动下一台机组，经**自动同期**后合闸并入电网，并自动均分负荷。

### 3. 自动解列与停机
多机在网、负载低于解列阈值（低载运行）时，电站延时自动将**最后并入**的机组分闸解列，随后自动停机，保持最少机组在网经济运行。

### 4. 故障自动换机（Ⅰ级故障）
Ⅰ级故障（如滑油低压、冷却水温高）属**报警级降级故障**：故障机组不停机、主开关不跳闸，由自动化电站检测后执行"备用机组自动并车 → 负荷全部转移 → 自动解列故障机组 → 自动停机"的带电换机流程，保证供电不中断。

### 5. 断电自动切换（Ⅱ级故障）
Ⅱ级故障（如欠压、汇流排短路）导致机组跳闸、母线失电时，自动化电站按备用顺序自动起动备用机组并合闸，**快速恢复供电**。

### 6. 重载问询
侧推器等大功率负载起动前先向电站发出**询问请求**：单机在网时电站应答"等待"（黄灯）并强制自动并车备用机组，待并车成功、容量充足后改答"允许"（绿灯），负载方可起动，从而避免起动冲击导致电网过载甚至失电。

## 四、典型操作任务

### 任务一：发电机组的自动并车、自动解列
1. 自动接线，起动 1# 发电机并合闸供电；
2. 将电站切换为**自动运行模式**；
3. 将负载有功功率设为 50kW 并点击"加载"→ 观察 2# 机组自动起动、自动并车、自动均分负荷；
4. 卸载负载 → 观察 2# 自动转移负荷、自动解列、自动停机。

### 任务二：Ⅰ级故障自动化电站带电换机
1. 自动接线，1# 机单机供电并将电站切至自动模式；
2. 设置 1# 机Ⅰ级故障（滑油低压 / 冷却水温高）；
3. 观察电站自动起动 2# 机组并车转移负荷、解列并停掉故障机组，1# 停机告警。

### 任务三：Ⅱ级故障自动化电站断电切换
1. 自动接线，1# 机单机供电并将电站切至自动模式；
2. 设置 1# 机欠压故障（Ⅱ级）；
3. 观察 1# 跳闸、母线失电，电站按备用顺序自动起动 2# 并合闸恢复供电。

### 任务四：重载问询功能实操
1. 自动接线，将电站切至自动模式，观察失电自动起动 1# ；
2. 勾选"重载询问面板"调出面板，选择开关切至"重载问询"模式；
3. 第 1 次按下"起动/询问"按钮 → 观察回应灯变黄（等待）、2# 自动并车、并车后回应灯变绿（允许）；
4. 再次按下按钮 → 侧推器负载起动，两台机组自动均分；
5. 按下"停止"按钮 → 重载退出、2# 自动解列停机，1# 继续单机供电。

## 六、操作提示

- 进入任务前请先在下拉框选择对应流程，再选择教学模式。
- 自动演示模式由系统逐步演示并闪烁箭头指示操作位置；演练/评估模式需学员自行操作。
- 观察并车过程请重点留意：**同步合闸瞬间**、负荷均分情况、回应指示灯颜色变化（黄→绿）。
- 故障演示建议按"Ⅰ级先于Ⅱ级"的顺序体验，对比两种故障处置的差异。

*本文档用于指导本仿真工程的教学使用，与工程各流程一一对应。*
